# TimeManager Phase 5 개발 로드맵

Phase 5에서는 루틴을 시간으로 등록하고 이른 시각부터 보는 흐름을 만든다. 할 일에는 23:59 마감 설정을 추가하고, 월간 캘린더는 이름 중심으로 표시하며 날짜 상세를 열고 닫을 수 있게 한다. [Phase 4 개발 로드맵](./phase-4.md) · [기능 요구사항](./feature-requirements.md)

## 개발 순서

### 1 루틴 시간 선택과 정렬

- 루틴 추가와 수정에서 시간 선택 입력을 사용한다. 시·분을 필수로 받고 유효한 `HH:mm` 값만 저장한다. 루틴 이름과 반복 요일 입력은 기존대로 제공한다.
- 데일리에서는 오늘 요일에 해당하는 루틴을 저장한 시각이 빠른 순서로 보여준다. 같은 시각의 루틴은 등록 순서를 유지한다. 시간을 수정하면 목록에서 위치가 바로 바뀐다.
- 기존에 `07:30`처럼 유효한 시간을 저장한 루틴은 그대로 시간으로 읽는다. `아침 먹고` 같은 문구가 저장된 루틴은 기존 문구와 완료 기록을 보존하고, 시간을 정한 항목 뒤에 등록 순서대로 보여준다. 해당 루틴을 수정해 저장할 때는 시간을 선택해야 한다. 루틴 ID와 날짜별 완료·보상 기록은 유지한다.
- **완료 기준** — 18:00 루틴을 먼저 등록하고 07:30 루틴을 나중에 등록해도 목록에는 07:30이 먼저 표시된다. 기존 문구가 있는 루틴도 열고 체크할 수 있다.

### 2 할 일 마감 시간 23:59 설정

- 할 일 추가·수정 양식에 **23:59로 설정** 체크박스를 둔다. 체크하면 선택한 마감 날짜의 23:59가 시간 입력에 들어간다. 해제하면 시간을 다시 직접 선택할 수 있다. 해제 직후에는 23:59를 입력값으로 유지한다.
- 일반 마감 시간과 동일한 형식으로 저장한다. 기존 마감순 정렬과 마감 전 완료 보상 규칙을 그대로 적용한다. 23:59 정각에 완료하면 보상은 지급하지 않는다.
- **완료 기준** — 마감 날짜를 선택하고 체크해서 저장하면 데일리와 캘린더 상세에 해당 날짜의 23:59가 표시된다.

### 3 월간 캘린더에서 이름 표시

- 월간 캘린더의 날짜 칸과 선택한 날짜의 상세 목록에서 항목 이름 앞에 앱이 자동으로 붙이던 **할 일**, **일정**을 제거한다. 사용자가 입력한 이름 전체와 지정 색상은 유지한다.
- 상세 목록에서 할 일은 완료 체크와 마감 시각, 일정은 종일 여부 또는 시작·종료 시각으로 구분할 수 있게 한다.
- **완료 기준** — 이름이 ‘장보기’인 할 일과 ‘병원’인 일정은 각각 입력한 이름으로 표시된다.

### 4 캘린더 날짜 선택과 상세 접기

- 캘린더 탭에 들어갈 때 이번 달을 보여 주고 날짜를 선택하지 않는다. 날짜 상세 영역과 그 안의 추가 버튼은 날짜를 선택하면 표시한다.
- 날짜를 한 번 누르면 해당 날짜의 상세를 열고, 같은 날짜를 다시 누르면 선택을 해제하고 상세 영역을 숨긴다. 다른 날짜를 누르면 해당 날짜의 상세로 바꾼다.
- 이전 달이나 다음 달로 이동하면 선택을 해제한다. 새로고침, 화면 갱신, 저장 이후에도 사용자가 누르지 않은 날짜를 자동으로 선택하지 않는다.
- **완료 기준** — 첫 진입 시 상세가 없고, 날짜를 눌러 열고 다시 눌러 닫을 수 있다. 상세를 연 뒤에는 선택 날짜를 기준으로 할 일과 일정을 추가할 수 있다.

### 5 회귀 테스트와 로컬 확인

- 기능과 자동 테스트는 `feature/phase-5`에서 별도 커밋으로 남긴다. 테스트 시나리오는 [test-scenarios.md](./test-scenarios.md)에 추가한다. PR에서 `node --test`로 전체 테스트를 실행하고 실패하면 원인·영향·수정안을 검토받은 뒤 수정한다. [프로젝트 작업 지침](../AGENTS.md)
- 로컬 웹에서 다섯 가지 변경과 기존 데이터 표시를 확인한 뒤 사용자에게 확인 링크를 제공한다. PR 검사 통과와 사용자 확인 및 명시적 승인 후 병합한다.
- 배포 후 Windows와 iPhone에서 시간 선택 입력, 23:59 체크박스와 캘린더 날짜 선택을 확인하고 기기별 검증 결과를 기록한다.

## 추가할 Given When Then 시나리오

| 시나리오 | Given | When | Then |
| --- | --- | --- | --- |
| 유효한 시간 필수 | 루틴 추가 또는 수정 양식이 열려 있다. | 시간을 비워 두거나 `24:00`을 넣어 저장을 시도한다. | 저장되지 않고 유효한 시간을 선택해야 한다. |
| 시간순과 동시간 정렬 | 오늘 반복하는 루틴이 18:00, 07:30, 07:30 순서로 등록됐다. | 데일리를 열고 18:00 항목을 07:00으로 수정한다. | 처음에는 07:30 두 항목이 등록 순서대로 앞에 나오고, 수정 후에는 07:00 항목이 맨 앞에 나온다. |
| 기존 문구 루틴 | `아침 먹고`가 저장된 루틴과 날짜별 완료 기록이 있다. | 데일리를 열고 해당 루틴을 08:00으로 수정한다. | 수정 전에는 시간 지정 루틴 뒤에 나오고, 수정 후에는 시간순으로 이동하며 기존 기록은 유지된다. |
| 23:59 마감 | 할 일 양식에서 날짜를 선택했다. | 23:59 설정을 체크하고 저장한다. | 선택 날짜의 23:59로 저장되며 정각 완료에는 보상이 지급되지 않는다. |
| 캘린더 이름 | 같은 날짜에 할 일과 일정이 있다. | 월간 캘린더를 열고 날짜를 선택한다. | 날짜 칸과 상세에 두 이름이 자동 접두어 없이 표시된다. |
| 날짜 선택 전환 | 캘린더 탭에 처음 들어왔다. | 날짜 A, 날짜 B, 날짜 B를 차례로 누른다. | 처음에는 상세가 없고, 상세가 A에서 B로 바뀐 뒤 닫힌다. |
| 월 이동 | 월간 캘린더에서 날짜 상세가 열려 있다. | 다음 달로 이동한다. | 새 달을 표시하고 날짜 선택과 상세 영역을 해제한다. |
