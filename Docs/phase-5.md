# TimeManager Phase 5 개발 로드맵

데일리의 **할 일** 탭에서 마감이 24시간 이내인 미완료 항목을 표시한다. 마감 시각이 지난 항목은 당일 동안 별도로 표시해, 지금 처리해야 하는 일과 마감이 지난 일을 구분할 수 있게 한다. [Phase 4 개발 로드맵](./phase-4.md) · [기능 요구사항](./feature-requirements.md)

## 표시 규칙

| 상태 | 조건 | 데일리 표시 |
| --- | --- | --- |
| 일반 | 미완료, 마감까지 24시간 초과 | 기존 이름과 마감 날짜·시간 |
| 마감 임박 | 미완료, 마감까지 24시간 이하이며 아직 마감 전 | 기존 정보와 **마감 임박** |
| 마감 지남 | 미완료, 마감 시각에 도달했고 마감일 당일 | 기존 정보와 **마감 지남** |
| 완료 | 완료 체크한 항목 | 기존 체크 및 취소선 표시 |

예를 들어 마감이 금요일 18:00이면 목요일 18:00부터 **마감 임박**, 금요일 18:00부터 **마감 지남**으로 표시한다. 토요일이 되면 데일리에서 빠지고 캘린더에 기록이 남는다. 24시간은 날짜 칸의 차이가 아니라 현재 시각과 마감 시각의 실제 차이로 계산한다. `PL-01` · `PL-05` · `PL-06`

## 개발 순서

### 1 마감 상태 판정과 화면 갱신

- 저장된 마감 날짜·시간을 기존 보상 판정과 같은 기기 현지 시각으로 해석한다. 완료 상태를 우선 판정하고, 미완료 항목은 마감까지 남은 시간에 따라 표시한다. 상태는 볼 때마다 계산해 기존 데이터도 바로 반영한다.
- 데일리 목록은 기존대로 마감이 가까운 순으로 표시한다. 마감일 당일에는 마감 시각 이후에도 체크할 수 있다. 마감 시각 전 완료에만 보상을 지급하는 기존 규칙을 유지한다.
- 기존 화면 갱신 주기를 사용해 데일리를 열어 둔 상태에서도 표시를 갱신한다. 앱에 다시 돌아오거나, 날짜·시간을 수정하거나, 완료·취소하면 즉시 다시 판정한다. 완료 취소 시 현재 시각에 맞는 표시가 돌아오며 이미 지급한 보상은 유지된다.
- **완료 기준** — 마감 직전과 정각에 표시가 구분되고, 데일리를 열어 둔 경우 다음 화면 갱신에서 바뀐다. 새로고침 후에는 현재 시각에 맞는 상태가 표시된다.

### 2 데일리 할 일 행에 상태 표시

- 할 일 이름과 마감 시각을 읽을 수 있도록 유지하면서 **마감 임박**과 **마감 지남**을 짧은 텍스트로 표시한다. 색 없이도 상태를 구분할 수 있게 한다.
- 기존 할 일 색상과 완료 체크, 수정·삭제 버튼을 유지한다. 표시 변경은 데일리의 할 일 탭에 적용한다.
- **완료 기준** — Windows와 좁은 모바일 화면에서 상태 문구와 마감 시각을 읽을 수 있고, 행의 버튼도 사용할 수 있다.

### 3 회귀 테스트와 로컬 확인

- `feature/phase-5`에서 기능과 자동 테스트를 각각 커밋한다. 테스트 시나리오는 [test-scenarios.md](./test-scenarios.md)에 추가하고, PR에서 `node --test`로 전체 테스트를 실행한다. 실패하면 원인·영향·수정안을 검토받은 뒤 수정한다. [프로젝트 작업 지침](../AGENTS.md)
- Windows 로컬 웹앱에서 마감 임박, 마감 지남, 완료 취소, 마감 시간 수정 흐름을 확인하고 사용자에게 로컬 확인 링크를 제공한다. PR 검사 통과와 사용자 확인 및 명시적 병합 승인 후 `main`에 병합한다.
- 배포 후 공개 웹앱에서 새 표시가 제공되는지 확인하고 Windows와 iPhone에서 확인한 범위를 기록한다.

## 추가할 Given When Then 시나리오

| 시나리오 | Given | When | Then |
| --- | --- | --- | --- |
| 24시간 기준 | 내일 18:00에 마감하는 미완료 할 일이 있다. | 현재 시각을 오늘 17:59:59에서 18:00으로 바꾸고 화면을 갱신한다. | 24시간을 초과할 때는 표시가 없고, 정확히 24시간 전부터 마감 임박이 표시된다. |
| 마감 정각 | 오늘 18:00에 마감하는 미완료 할 일이 있다. | 마감 직전에서 정각으로 시각을 바꾸고 화면을 갱신한다. | 마감 임박에서 마감 지남으로 바뀐다. 정각에 완료해도 보상은 지급되지 않는다. |
| 완료와 취소 | 마감 임박 항목이 있다. | 완료한 뒤 마감 시각이 지나고 같은 날 완료를 취소한다. | 완료 상태에선 표시가 사라지고, 취소 후 마감 지남이 표시된다. 이미 지급된 보상은 유지된다. |
| 마감일 경과 | 어제 마감한 할 일이 있다. | 데일리와 캘린더를 연다. | 데일리 목록에서는 빠지고 캘린더의 마감일에는 기록이 남는다. |
| 마감 수정 | 마감까지 24시간 이내인 미완료 항목이 있다. | 마감을 24시간 뒤보다 더 늦게 바꾼다. | 마감 임박 표시가 사라지고 기존 마감순 정렬에 따라 위치가 바뀐다. |
