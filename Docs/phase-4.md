# TimeManager Phase 4 개발 로드맵

Phase 4에서는 퀘스트 보상으로 받은 먹이를 모아 아홀로틀을 성장시킨다. 부화 직후부터 성장까지 데일리 상단에서 진행 상황을 확인할 수 있다. [Phase 3 개발 로드맵](./phase-3.md) · [기능 요구사항](./feature-requirements.md)

## Phase 4 범위

| 상태 | 조건 | 데일리 상단 표시 |
| --- | --- | --- |
| 알 | 첫 보상을 받았고 부화하지 않았다. | 기존 알 스티커, 먹이 잔량, 부화 버튼 |
| 부화 직후 | 부화 후 먹인 횟수가 0~4회다. | 기존 아홀로틀 스티커, 현재 단계, 성장까지 남은 횟수, 먹이 잔량 |
| 성장 완료 | 부화 후 먹인 횟수가 5회 이상이다. | 성장한 아홀로틀 스티커, 성장 완료 상태, 누적 먹인 횟수, 먹이 잔량 |

육성 대상은 기존 아홀로틀 한 종이다. 기존 퀘스트 보상 규칙과 알을 부화시키는 비용은 Phase 1·2에서 정한 기준을 따른다. [Phase 1 개발 로드맵](./phase-1.md) · [Phase 2 개발 로드맵](./phase-2.md)

## 개발 순서

### 1 성장 판정과 기존 기록 반영

- 부화 후 먹인 누적 횟수로 단계를 계산한다. 단계 판정에 기존 저장 기록을 사용해 업데이트 전 횟수도 인정한다. 이미 5회 이상이면 업데이트 후 데일리를 처음 열 때 성장 완료 상태가 표시된다. `GR-03`
- 알 부화에 쓰는 먹이 1개는 성장 횟수에서 제외한다. 부화 후에는 먹이 1개 사용과 횟수 1회 증가를 한 번에 저장한다. 잔량이 0이면 실행할 수 없고, 저장에 실패하면 이전 잔량과 횟수를 유지하고 오류를 표시한다.
- 네 번째에서 다섯 번째 먹이 주기로 넘어갈 때 성장 완료 상태로 바뀐다. 이후에도 먹이를 줄 수 있으며, 먹이 1개를 사용할 때마다 누적 횟수가 1회 증가한다.
- **완료 기준** — 저장된 횟수 4회와 5회에서 서로 다른 단계가 표시된다. 5회째 먹이 주기를 저장한 뒤 앱을 다시 열면 성장 상태와 잔량이 유지된다.

### 2 데일리 카드와 성장 스티커

- 기존 아홀로틀과 같은 캐릭터로 알아볼 수 있도록 분홍색과 스티커 스타일을 유지하고, 실루엣이나 장식에서 차이가 나는 성장 이미지 1종을 준비한다. 기존 카드에서 두 단계를 구분할 수 있도록 표시하고 이미지에 대체 텍스트를 제공한다.
- 성장 전에는 `성장까지 먹이 2회`처럼 남은 횟수를 표시한다. 성장 후에는 `성장 완료`와 누적 먹인 횟수를 표시한다. 먹이 주기로 처음 성장한 경우에만 성장 안내를 띄운다.
- 서비스 워커 캐시를 갱신하고 성장 이미지를 캐시 목록에 추가해 최신 버전을 온라인에서 한 번 연 뒤 오프라인에서도 표시되도록 한다.
- **완료 기준** — 데일리 상단에서 현재 단계와 먹이 잔량을 확인할 수 있고, 5회째 먹이를 주면 문구와 이미지가 함께 바뀐다.

### 3 자동 테스트와 로컬 확인

- `feature/phase-4`에서 기능을 구현해 커밋하고, 자동 테스트와 [테스트 시나리오](./test-scenarios.md) 갱신을 별도로 커밋한다. PR에서 `node --test`로 전체 테스트를 실행한다. 실패 시 원인·영향·수정안을 사용자에게 검토받은 뒤 수정하고 다시 실행한다. [프로젝트 작업 지침](../AGENTS.md)
- Windows 로컬 웹에서 성장 전후, 새로고침, 먹이 소진 상태를 확인하고 같은 링크를 사용자에게 제공한다. PR 검사 통과와 사용자 기능 확인 및 명시적 병합 승인 후 `main`에 병합한다.
- 배포 후 공개 웹앱에서 성장 이미지와 기존 진행 상태를 확인한다. Windows 브라우저와 iPhone Safari에서 확인한 결과를 구분해 기록한다.

## 추가할 Given When Then 시나리오

| 시나리오 | Given | When | Then |
| --- | --- | --- | --- |
| 성장 기준 | 부화 후 3회 먹였고 먹이가 2개 있다. | 먹이를 한 번씩 두 번 준다. | 4회에는 성장까지 1회로 표시된다. 5회에는 성장 이미지가 표시되고 잔량은 0개다. |
| 기존 횟수 반영 | 업데이트 전에 부화한 몬스터에게 5회 이상 먹였다. | 업데이트한 앱에서 데일리를 연다. | 추가 먹이를 쓰지 않아도 성장 완료 상태, 기존 횟수와 잔량이 표시된다. |
| 성장 이후 계속 먹이기 | 성장 완료 상태이고 먹이가 1개 있다. | 먹이를 준 뒤 앱을 다시 연다. | 성장 완료 상태가 유지되고, 누적 횟수가 1회 증가하며 잔량은 0개다. |
| 부화 비용 | 알과 먹이 1개가 있다. | 알을 부화시킨다. | 잔량은 0개이며 부화 후 먹인 횟수는 0회다. |
| 성장 시점의 저장 실패 | 부화 후 4회 먹였고 먹이 1개가 있으며 기기 저장이 실패한다. | 먹이를 준다. | 오류가 표시되고 성장 전 상태, 4회 기록 및 잔량 1개가 유지된다. |
