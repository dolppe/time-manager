# TimeManager 기능 요구사항

TimeManager는 반복 루틴과 마감이 있는 할 일을 관리하고, 완료 보상으로 알을 부화시키고 몬스터를 키우는 웹앱이다. iPhone과 Windows PC의 브라우저에서 사용할 수 있으며, 일정과 완료 기록, 육성 진행 상태는 별도 데이터 저장 서버 없이 사용하는 기기에 저장한다.

이 문서를 기능 추가와 변경을 반영하는 기준으로 삼는다. 개발 로드맵에서는 아래 기능 ID를 참조해 작업 범위와 선행 기능을 연결한다.

## 화면 구성

| ID | 화면 | 역할 |
| --- | --- | --- |
| UI-01 | 데일리 | 오늘의 루틴과 마감이 있는 할 일을 관리한다. 화면 상단의 **루틴**과 **할 일** 탭으로 전환한다. |
| UI-02 | 캘린더 | 월 단위로 할 일과 일정을 조회하고 등록한다. |

화면 하단에서 **데일리**와 **캘린더**를 전환한다. 키우기 기능의 진입 위치는 추후 결정한다.

## 루틴

- **RT-01 루틴 추가** — 데일리의 루틴 탭에서 추가한다. 각 루틴에는 **시간 또는 원하는 문구**, **루틴 내용**, **반복 요일**을 지정한다. 반복 요일은 월요일부터 일요일까지 원하는 요일을 선택한다. 예를 들어 `07:30 / 스트레칭 / 월·수·금`이나 `운동 끝나고 / 물 마시기 / 매일`을 등록할 수 있다.
- **RT-02 오늘의 루틴 표시** — 오늘 요일에 해당하는 루틴을 처음 등록한 순서대로 보여준다. 시간이나 문구는 표시 정보로 사용하며 목록 순서는 등록 순서로 유지한다.
- **RT-03 날짜별 완료 체크** — 루틴은 한 항목 단위로 체크한다. 완료하면 해당 항목이 회색과 취소선으로 바뀌고 체크 표시가 나타난다. 완료 상태는 그날의 실행에 적용되므로 같은 루틴이 다음 반복일에 다시 나타나면 새로 체크할 수 있다.

## 할 일과 일정

| ID | 유형 | 등록 항목 | 완료 처리 |
| --- | --- | --- | --- |
| PL-01 | 할 일 | 이름, 표시 색상, 마감 날짜와 시간 | 데일리에서 완료 체크한다. 마감 시각 전에 완료하면 퀘스트 보상 조건을 충족한다. |
| PL-02 | 일정 | 이름, 표시 색상, 시작일과 종료일. 종일 또는 시작·종료 시간 지정 | 월간 캘린더에서 조회한다. |

- **PL-03 월간 캘린더 표시** — 할 일과 일정을 모두 표시한다. 할 일은 마감일에, 일정은 해당 기간에 표시한다. 등록한 이름과 색상을 사용하며 두 유형을 서로 구분할 수 있게 표시한다. 구체적인 표시 방식은 화면 설계에서 정한다.
- **PL-04 일정의 날짜와 시간** — 종일 일정과 시간 지정 일정을 지원한다. 시간 지정 일정은 시작일과 종료일이 같거나 다를 수 있다. 예를 들어 하루 종일인 휴가나 금요일 오후에 시작해 토요일 오전에 끝나는 일정을 등록할 수 있다.
- **PL-05 데일리 할 일 목록** — 마감 날짜와 시간이 가까운 항목부터 나열한다. 마감일 당일에는 마감 시각이 지나도 목록에서 볼 수 있으며, 마감일이 지나면 데일리 목록에서 빠진다. 데일리의 목록 표시 기간과 퀘스트의 보상 기준 시각을 각각 적용한다.
- **PL-06 할 일 완료 체크** — 데일리의 할 일 탭에서 체크하고 완료 상태를 확인할 수 있다. 보상 조건을 판정할 때는 체크한 시각과 등록한 마감 시각을 비교한다.

## 퀘스트와 몬스터 키우기

| ID | 기능 | 요구사항 |
| --- | --- | --- |
| GR-01 | 퀘스트 완료 | 당일 루틴을 완료하거나 할 일을 마감 시각 전에 완료하면 퀘스트가 완료되고 보상을 받는다. |
| GR-02 | 퀘스트 보상 | 보상 후보에는 알, 알을 부화시키는 먹이, 부화한 몬스터를 키우는 먹이가 있다. 최종 보상 목록과 지급 조건은 추후 확정한다. |
| GR-03 | 부화와 육성 | 퀘스트 보상으로 받은 알을 먹이로 부화시키고, 부화한 몬스터에게 먹이를 주어 키운다. |

## 주요 동작 확인 기준

| 관련 기능 | 확인할 동작 |
| --- | --- |
| RT-01~03 | 월·수·금 루틴은 화요일 목록에 나오지 않는다. 먼저 등록한 루틴은 시간이 늦더라도 위에 표시된다. 월요일에 체크하면 회색 취소선과 체크 표시가 나타나고 수요일 항목은 미완료로 표시된다. |
| PL-01, PL-05~06 | 마감이 가까운 할 일이 위에 표시된다. 마감일 당일에는 목록에서 완료 여부를 볼 수 있고, 다음 날에는 데일리 목록에서 빠진다. |
| PL-02~04 | 종일 일정과 이틀에 걸친 시간 지정 일정을 등록할 수 있다. 월간 캘린더에 이름과 지정 색상이 보이고, 할 일과 일정은 구분되어 표시된다. |
| GR-01~03 | 루틴 완료와 마감 전 할 일 완료는 각각 보상으로 이어진다. 같은 날이라도 마감 시각이 지난 뒤 체크한 할 일에는 보상이 지급되지 않는다. 획득한 알은 부화시키고 몬스터는 먹이로 키울 수 있다. |
| 기기 저장 | 같은 기기에서 웹앱을 다시 열면 등록한 항목과 완료 상태, 육성 진행 상태를 확인할 수 있다. |

## 로드맵에서 참조할 선행 관계

- 데일리의 루틴 목록은 등록한 반복 요일과 등록 순서를 사용한다. 완료 표시는 날짜별 루틴 기록과 연결된다.
- 데일리의 할 일 목록과 월간 캘린더는 같은 할 일 기록을 사용한다. 정렬과 보상 판정은 마감 날짜와 시간을 사용하고, 데일리에서 목록을 숨기는 기준은 마감일을 사용한다.
- 퀘스트 보상은 루틴의 날짜별 완료와 할 일의 마감 전 완료 결과에 의존한다. 부화와 육성에는 지급된 알과 먹이의 기록이 필요하다.

## 추후 결정할 사항

- **일정과 할 일 표시** — 캘린더에서의 구체적인 구분 방식, 마감일이 지난 할 일의 캘린더 표시, 루틴·할 일·일정의 수정 및 삭제 동작.
- **완료와 보상 처리** — 마감 시각과 정확히 같은 시각에 체크한 경우, 완료를 취소했다가 다시 체크하는 경우의 보상 처리, 항목당 지급 횟수.
- **육성 규칙** — 보상의 종류와 지급량, 알 획득 및 부화 조건, 몬스터 성장 조건, 키우기 화면 진입 위치.
